# Boss Picker

Students' bosses for Super Mario Construct, hosted as one site.

- **Add bosses:** open the `turned-in` folder here, click **Add file > Upload files**, drag in student zips (named with code names), and click **Commit changes**. The site rebuilds itself in about 3 to 5 minutes.
- **Remove a boss:** open its zip in `turned-in`, click the trash icon, and commit.
- **Picker:** `https://YOUR-NAME.github.io/smc-bosses/bosses.html`
- **Watch a build:** the **Actions** tab. Green check = live.

Every Monday it also checks LSS for a game update and rebuilds by itself.
